# 五种电路层人为故障

**简体中文** | [English](dut_fault_matrix.en.md)

性质：为检验验证环境主动注入的错误，不是真实芯片缺陷。正常默认参数全为 0；禁用错误分支后运行完整正向回归。

| 故障 | 注入方式 / 根因 | 应有行为 | 抓错检查 |
|---|---|---|---|
| 提前写入 | 准备阶段修改 DATA | 完成的合法写才更新 | no setup write |
| 丢错误响应 | 将 PSLVERR 强制为 0 | 非法访问完成时报告错误 | error response |
| 只读保护失效 | 写地址 04 时仍覆盖 DATA，同时仍报错 | 报错且 DATA 不变 | commit exactly at completion |
| 错误复位值 | DATA 复位为 1 | 异步清零 | asynchronous reset |
| 错误读数据 | DATA 读响应最低位翻转 | 返回实际保存的值 | readback |

## 复现

`make faults` 在等待 0、1、3 下测试提前写；`make dut-faults` 固定等待 1，逐项编译并测试其余四种。每次只启用一种错误，要求非零退出并命中特定检查名称。

附加故障日志在 `build/dut_faults/fault_<1到4>/run.log`。这些负向构建独立保存，不修改正常构建参数。

## 检查设计要点

只读保护案例不仅看 PSLVERR：错误实现虽然正确报错，却仍然破坏 DATA。检查器在完成后的寄存器值比较中发现副作用。

读响应案例修改的是电路输出，与之前在 monitor 中污染观察记录不同：前者验证实际 DUT 输出路径，后者验证比较器接到坏数据会不会报错。

复位案例在任何正常读写之前失败，说明复位检查并非依赖后面随机读到异常才发现。
