# 测试矩阵

**简体中文** | [English](test_matrix.en.md)

## 功能场景

| 场景 | 检查内容 |
|---|---|
| 异步复位 | 指针、数量、输出数据和状态标志 |
| 单次写入与读取 | 数量变化和返回数据 |
| 有序数据流 | 先进先出顺序 |
| 重复空读 | 状态和 `rd_data` 保持 |
| 填满与排空 | 每个数量等级和边界标志 |
| 满状态拒绝写入 | 原有数据保持完整 |
| 正常同时读写 | 返回队首、加入队尾、数量保持 |
| 空状态同时请求 | 接受写入、拒绝读取 |
| 满状态同时请求 | 接受读取、拒绝写入 |
| 多次指针回卷 | 地址合法性和数据顺序 |

## 断言

| 性质 | 适用场景 |
|---|---|
| 复位清空 | 异步复位和保持复位 |
| 空读保持 | `empty && rd_en` |
| 满写保持 | `full && wr_en` |
| 正常同时读写数量保持 | `wr_en && rd_en && !empty && !full` |
| 数量范围合法 | `0 <= data_count <= DEPTH` |
