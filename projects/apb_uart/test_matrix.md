# APB 基线定向场景

**简体中文** | [English](test_matrix.en.md)

| 场景 | 检查 |
|---|---|
| 复位后读取 DATA / ID | 分别为 0 / 1 |
| 写入 2A、FFFFFFFF、A5A55A5A 后读取 | 内容一致 |
| 写只读地址 04 | 错误；ID 和 DATA 不变 |
| 读写非法地址 08 / 不对齐地址 01 | 错误；DATA 不变；错误读为 0 |
| 连续传输 | psel 保持选中，每笔仍经过准备阶段 |
| 等待 0、1、3 拍 | 实际等待数准确；准备、等待时不提前写 |
| 非零数据后复位 | DATA 恢复为 0 |
| 未完成写入时复位 | 零等待组在准备阶段复位，其余组在等待访问中复位 |
| 复位后重新读写 | 能恢复正常操作 |
| 人为提前写入 | 检查器必须报 no setup write |

每个等待配置完成 20 笔事务，另有一笔被复位取消的请求；取消请求不计入完成数。尚未遍历所有非法地址，也没有宣称覆盖率 100%。

## APB + UART 扩展

| 场景 | 检查 |
|---|---|
| TXDATA 写入与串行输出 | 完成沿之后才发送；起始位、低位先发的 8 数据位、停止位和空闲电平 |
| TX→RX 回环 | 同一帧从输出线返回接收器，RXDATA 必须读回原字节 |
| 发送忙时再次写入 | APB 错误响应；当前发送不被覆盖 |
| RX 串行输入与 RXDATA 读取 | 8N1 帧还原为字节；完成读后 `rx_valid` 清零 |
| 接收缓冲已满 | 新帧丢弃，旧数据保留，`rx_overrun` 置位 |
| 停止位为低 | 无新数据，`framing_error` 置位 |
| 复位中断发送 | `tx_o` 立即回高，状态和错误位清零 |
| 非法地址、权限、高位非零写入 | 错误响应且无副作用 |
| 8/16 时钟每位 × 0/1/3 拍 APB 等待 | 六组配置都通过相同自检 |
